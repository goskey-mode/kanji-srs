# kanji-srs

間違えた問題（漢字・計算・記述など）を忘却曲線に沿って繰り返し出題する、家庭用の間隔反復アプリ。

- **データ**: Google Apps Script（GAS）＋スプレッドシート＋Drive（`gas/`）。保護者のアカウントで動く
- **画面**: 静的ページ（`app/`）。GitHub Pages で配信
  - `study.html` — 子ども用（タブレット）。今日の問題 → 答え → ○△× を自己採点
  - `admin.html` — 保護者用（スマホ・PC）。登録・一覧・状況

画面を GAS の外に置くのは、13歳未満の Google 子どもアカウントでは `script.google.com` の Web アプリが開けないため。画面は `fetch`（`credentials: 'omit'`）で GAS の `doPost` を呼ぶ。

## 復習のルール

- 間隔は 1 → 3 → 7 → 14 → 30 → 60 日。○で次の段階、△で同じ間隔をもう一度、×で最初から
- 60日後の復習で○なら卒業。180日後に1回だけ抜き打ち（○で完全卒業、×で復活、△は30日後に再度）
- 1日の量は既定10分（見積もり: 書き20秒・読み10秒・語句15秒・写真問題90秒）。段階の低いカードから積み、新しいカードは1日4枚まで。あふれた分は翌日以降へ
- 1日の区切りは午前3時。連続日数は「その日の分を終えた日」で数え、休んだ日はお休みチケット（月2枚）を自動で使う
- 設定はスプレッドシートの `settings` シートで変えられる

## セットアップ

1. Google スプレッドシートを作成 →「拡張機能」→「Apps Script」
2. プロジェクトの設定で「appsscript.json マニフェスト ファイルをエディタで表示する」をオン
3. `gas/appsscript.json` と `gas/Code.gs` をエディタに貼り付ける
4. `SETUP_STUDY_PIN`（子ども用）と `SETUP_ADMIN_PIN`（保護者用）に別々の6桁以上の数字を入れて `setup` を実行。権限は「このアプリが作成した Drive ファイル」「このスプレッドシート」「外部サービスへの接続」の3つだけ。実行後、2つの PIN は空に戻してよい
5. デプロイ → ウェブアプリ（実行ユーザー: 自分 / アクセス: 全員）。コード更新時は「デプロイを管理」→ 新バージョン（URLは変わらない）
6. 端末で `https://<user>.github.io/kanji-srs/app/#api=<URLエンコードした Web app URL>` を開く（`#` 以降はサーバに送られず、端末に保存された後アドレス欄から消える）

接続先URL・PIN・データはリポジトリに含めない。
